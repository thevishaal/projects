# 🚀 100 Days, 100 Python Projects

Welcome to **100 Days, 100 Python Projects** — a personal challenge to build **one Python project every day for 100 days**.
The goal is to strengthen **problem-solving skills**, **core Python concepts**, and **real-world project experience**.

---

## 📌 Challenge Goals

* 🔹 Improve Python fundamentals
* 🔹 Learn by building real projects
* 🔹 Practice clean code & documentation
* 🔹 Build a strong GitHub portfolio
* 🔹 Prepare for internships & jobs

---

## 🧰 Tech Stack

* **Language:** Python 🐍
* **Concepts:** OOP, File Handling, APIs, CLI Apps
* **Libraries:** os, sys, random, datetime
* **Tools:** Git, GitHub, VS Code

---

## 📁 Project Structure

```
python/
│
├── Day01_ProjectName/
│   ├── main.py
│   ├── README.md
│
├── Day02_ProjectName/
│   ├── main.py
│   ├── README.md
│
├── ...
│
└── README.md
```

Each project folder contains:

* `main.py` → Project source code
* `README.md` → Project explanation
