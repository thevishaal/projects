# 🎯 Rock Paper Scissors (Python)


## 📌 Description
**Rock Paper Scissors** is a simple **command-line based game** developed,
In this game, the player competes against the computer. The computer makes a random choice, and the result (win, lose, or draw) is decided based on predefined rules.
---

## ⚙️ Features
- 🎮 Player vs Computer gameplay
- 🔄 Random computer choice generation
- 🧠 Accurate win / lose / draw logic
- 📊 Score tracking system
- 🔁 Continuous gameplay loop
- ❌ Exit option at any time
---

## 🛠 Concepts Used
- Python Functions
- Conditional Statements (`if-elif-else`)
- Loops (`while`)
- random Module
- User Input Handling
- Dictionaries
- Basic Game Logic
---


## ▶️ How to Run
1. Make sure **Python 3.x** is installed on your system
2. Clone the repository or download the source file
3. Open terminal / command prompt and run:

```bash
python main.py
